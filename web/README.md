# 판정기 화면

판정기 결과를 보는 화면입니다(React + Vite). 그록봇(Grok)의 채팅 화면을 참고해, 대본을 넣으면 판정봇이 말풍선으로 판정과 고칠 곳을 답하는 채팅형으로 만들었습니다(D34). 판정 서버(`judge/serve.py`)가 빌드한 화면(`web/dist`)을 같이 내줍니다.

## 띄우기

저장소 맨 위 폴더에서 실행하고 `http://127.0.0.1:8787`을 엽니다.

```sh
./judge.sh web            # 또는 python3 -m judge.serve [--port 8787]
```

`web/dist`는 저장소에 넣어 두므로 Node.js 없이도 뜹니다. 화면을 고쳤을 때만 다시 빌드합니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 첫 화면 「판정해 보기」 | 입력 탭은 두 개입니다. 「쇼더스로 대본 만들기」에서 원래 글을 넣으면 쇼더스가 만든 대본을 판정합니다. 「가진 대본 넣기」에서는 넣은 대본을 판정합니다(원래 글은 선택). 「예시 넣기」 단추는 지금 탭의 칸을 모아 둔 글과 대본으로 채웁니다. 쇼더스 키가 없거나 하루 한도를 다 썼으면 쇼더스 탭을 끕니다. 판정봇은 받은 대본, 기준마다 판정 후 채워지는 확인 목록, 고치는 단계, 결론, 만들 대본을 차례로 보여 줍니다. 「세부정보 보기」에는 기준 10개, 넣은 글, 표기·길이, 고친 대본이 있습니다. 판정이 끝나면 같은 글로 쇼더스 대본을 한 번 더 받을 수 있습니다 |
| 모아 둔 대본 | 대본 98개와 최종 판정기(5판)의 판정. 통과·보류·탈락, 시험용, 채점자와 다르게 본 대본으로 거릅니다 |
| 판정기를 믿을 근거 | 시험용 50개를 채점자 정답과 견준 숫자 세 개와 판정기가 틀린 대본. 「숫자 자세히 보기」에서 개발용·전체와 다수결·확신 정답을 골라 봅니다 |

결과 카드는 판정 대신 결정을 보여 줍니다(`judge/view.py`의 `decision_of`, 고쳐 다시 판정했으면 `judge/revise.py`의 `choose`).

| 판정 | 결정 |
|---|---|
| 통과, 고친 대본 없음 | 그대로 만들어도 됨 |
| 통과, 고친 대본 있음 | 고친 대본으로 만듦 |
| 보류·탈락 → 고친 대본이 다시 판정에서 통과 | 고친 대본으로 만듦 |
| 보류·탈락 → 고친 대본도 통과 못 함, 탈락 아닌 대본이 있음 | 사람이 보고 정함(걸린 곳이 가장 적은 대본을 같이 보임) |
| 보류·탈락 → 고친 대본까지 모두 탈락 | 만들지 않음 · 사실 틀림 |

고친 대본은 두 가지입니다(`revision.method`).

- `reading_only`: 통과한 대본에서 목소리가 잘못 읽을 표기와 매번 틀리게 읽는 숫자만 코드가 바로 읽히게 바꿉니다.
- `model`: 모델은 대본이 보류·탈락한 이유가 된 부분만 고치고, 판정기는 처음부터 다시 판정합니다(한 번, `JUDGE_REVISE_ROUNDS`로 바꿈). 넣은 글의 숫자가 빠지거나 넣은 글에 없던 숫자가 들어간 장면과, 걸리지 않았는데 바뀐 장면은 코드가 되돌립니다(`reverted`). 화면은 다시 판정한 결과를 고친 대본 제목에 적습니다.

화면이 할 수 있는 일은 띄운 곳에 따라 달라집니다. 화면 글자에는 서버나 키 이야기를 쓰지 않으므로 차이는 여기에만 적습니다.

| 띄운 곳 | 모아 둔 대본을 누르면 | 글 넣어 쇼더스 대본 받기 | ▶ 듣기 |
|---|---|---|---|
| 판정 서버, `claude` 명령 또는 `ANTHROPIC_API_KEY` 있음 | 새로 판정(약 20~40초·약 $0.01. 보류·탈락이면 결론을 먼저 보이고 고친 대본까지 약 1분) | `SHORTUS_API_KEY`가 있고 한도가 남았을 때(아니면 대본 직접 넣기) | `SHORTUS_API_KEY`가 있을 때 |
| 판정 서버, 판정 못 함 | 저장해 둔 결과 | 없음 | 위와 같음 |
| 정적 파일만(`web/dist`를 다른 곳에 올림) | 저장해 둔 결과 | 없음 | 없음 |

- 소리는 쇼더스 「목소리 미리 듣기」(크레딧 0, `judge/listen.py`의 `tts`)로 받아 `audio/listen/`에 모아 둡니다. 고친 장면은 고친 문장을 읽힙니다.
- 쇼더스에서 새 대본 받기(`POST /api/fresh`, `judge/fresh.py`)는 `SHORTUS_API_KEY`가 있을 때만 씁니다. 쇼더스 하루 한도(대본 만들기 100번)를 쓰므로 판정 서버도 하루 20번(`FRESH_DAILY_LIMIT`), 같은 주소에서 1분 2번까지만 보냅니다(가정값). 키가 없거나 쇼더스 하루 한도를 다 썼으면(1분마다 `GET /v1/meta/quota-status`로 확인, 크레딧 0) 「쇼더스로 대본 만들기」 탭과 「같은 글로 쇼더스 대본 한 번 더 받기」를 끕니다. 오늘 더 받을 수 있는 횟수(쇼더스와 판정 서버의 남은 횟수 중 작은 쪽)를 쇼더스 탭 아래에 보여 줍니다. 한도를 다 썼으면 자정에 풀린다고 적습니다. 대본을 받지 못해 모아 둔 대본의 결과를 대신 보여 줄 때는 판정봇이 그 까닭을 먼저 말합니다.
- 판정 서버는 `Accept: application/x-ndjson`으로 부르면 기준 하나가 끝날 때마다, 고치기 단계를 시작할 때마다 한 줄씩 흘려보냅니다. 화면의 확인 목록은 이 줄로 채워집니다. 기준 10개가 끝나면 서버가 고치기 전 결론(`judged`)을 보냅니다. 화면에는 결론이 먼저 나오고, 고치기가 끝나면 고친 대본이 이어집니다.
- 연습 모드: 주소에 `demo=1`을 붙이면(예: `#/?t=blog-01-g1&demo=1`) 서버에 보내지 않고 저장해 둔 결과를 기준 하나씩 채웁니다. 모델 호출 없이 화면 배치를 볼 때 씁니다.

## 서버

| 주소 | 하는 일 |
|---|---|
| `GET /api/judge` | `{"judge": true, "ready", "model", "backend", "criteria"}` |
| `POST /api/judge` | 본문 `{"source": 넣은 글, "scenes": [{"text", "sec"}]}`. `sec`(쇼더스 예상 초)가 없으면 글자 수 × 0.1764초로 어림 |
| `GET /api/tts`, `POST /api/tts` | `{"tts": true, "ready"}`, 본문 `{"text"}` → WAV |

응답은 `judge/view.py`의 `to_view` 모양에 `input`, `request_id`를 더한 것이고, 화면 자료의 결과와 같은 모양입니다(`src/types.ts`의 `Result`). 같은 주소에서 1분에 5번(`JUDGE_PER_MINUTE`), 동시에 2건(`JUDGE_MAX_CONCURRENT`)까지 받습니다. 모델과 호출 경로는 판정기와 같은 환경 변수(`JUDGE_MODEL`, `JUDGE_BACKEND`)를 씁니다.

## 화면 자료와 빌드

Node.js 20 이상이 필요합니다. `web` 폴더에서 실행합니다.

```sh
npm install
npm run export   # public/data.json을 다시 만듦 (python3 scripts/export_data.py)
npm run build    # dist/에 정적 파일. 하위 경로에 올려도 열림
```

- `export`는 대본 98개(`data/scripts`), 넣은 글, 정답 두 가지(`data/labels/consensus.csv`, `consensus-sure.csv`), 시험용 표시(`data/labels/test.txt`), 5판 결과(`results/v5-all98`)를 읽습니다. 저장한 표 수에 지금 판정 선을 다시 적용합니다(`tools/evaluate.py --redecide`와 같은 셈).
- 「판정기를 믿을 근거」의 숫자도 같은 셈으로 내고, 끝에 `tools/evaluate.py --redecide`의 출력과 대조해 다르면 멈춥니다.
- 개발 서버: `JUDGE_ALLOW_ORIGINS=http://localhost:5173 python3 -m judge.serve`(맨 위 폴더)와 `VITE_JUDGE_API=http://127.0.0.1:8787/api/judge npm run dev`(`web` 폴더).
- Cloudflare 터널로 바깥에 열 때는 `JUDGE_TRUST_PROXY=cloudflare`로 `CF-Connecting-IP`에서 방문자 주소를 읽어 주소마다 1분간 요청 횟수를 셉니다. `JUDGE_ALLOW_COUNTRIES=KR`이면 해외에서 온 판정·대본·소리 요청을, `JUDGE_BLOCK_BOTS=1`이면 수집봇을 막습니다(robots.txt로 모두 막음, noindex, 봇 User-Agent는 403).
